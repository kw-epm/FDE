# Team seat management

Each plan includes a fixed number of seats; additional seats are billed pro-rata.

## Add a seat

1. Admin → Team → Invite.
2. Email the invitee.
3. New seat is billed at the next renewal (pro-rated).

## Remove a seat

1. Admin → Team → select user → Remove.
2. The seat is freed immediately; no refund for the current cycle (cycle continues until the next renewal).

The AI agent can walk through these steps but cannot remove or invite users on the customer's behalf — the customer's admin must execute the action.
