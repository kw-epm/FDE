# Free-tier limitations

The Free plan is meant for trial / personal use:

- 1 user / seat.
- 100 API calls / day.
- 500MB workspace storage.
- Community support only (no SLA, no live agent).
- Public-only content (no SSO, no SAML, no audit log).

## When to recommend an upgrade

If a Free customer asks about features only available on paid tiers, the agent surfaces the relevant tier and links to the upgrade page. **Does not** apply discounts or trial extensions on its own.
