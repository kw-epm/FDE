# Export your CloudServe data

Customers can request a full export of their account data at any time. Self-service for most plans; human approval required for Enterprise.

## What's included in an export

- All workspace content (documents, projects, configurations).
- Activity log (last 12 months).
- Team / user list.
- Audit log (Business and Enterprise only).
- Billing history (invoices PDF + CSV).

## Steps

1. **Profile → Privacy → Request export** for Free / Starter / Pro / Business — the export runs asynchronously and emails a signed download link when ready (typically 30 minutes; up to 24 hours for large workspaces).
2. **Enterprise** customers: the agent files an export request and **compliance reviews** (privacy team checks for any tenant-isolation considerations).

## What the AI does

- Confirms the request and the workspace scope.
- For Free / Starter / Pro / Business: kicks off the self-service export.
- For Enterprise: pre-fills the export ticket and routes to compliance.
- Provides ETA based on workspace size.
