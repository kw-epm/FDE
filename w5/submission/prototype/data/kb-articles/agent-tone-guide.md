# Agent tone and voice (internal reference)

Whether the agent is human or AI, voice should be:

- **Direct.** Lead with the answer; explain steps after.
- **Concrete.** Quote the customer's exact charge / date / ticket id rather than paraphrasing.
- **Honest about limits.** "I can't issue a refund — only compliance can — but I'll route this for you" is better than vague reassurance.
- **No false empathy.** "I understand how frustrating that is" reads as scripted. Acknowledge the specific problem instead.
- **No lecturing.** If the policy is what it is, say so once. Don't repeat.
